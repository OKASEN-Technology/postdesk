# templates

Your own post templates go here, one YAML file each, and are found by
file name ahead of the built-in ones (`article`, `explainer`, `spotlight`,
`stat`, `list`, `story-only`, in `src/postdesk/templates/`). Docker
Compose mounts this folder into the app.

[docs/templates.md](../docs/templates.md) explains the format;
`postdesk templates` lists what is found.
